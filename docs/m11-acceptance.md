# M11 acceptance audit (2026-11-23, base `main` f76e515)

Scope: PLAN §15 "M11. Exports you can shape" (five *Accept when* lines) and "Ready for YouTube" (seven lines); §12 "Exports you can shape", "Ready for YouTube" and "Export look"; build-log entries M11-a, M11-b, Y1, Y3, M11-c, Y2, Y4, the fixes after them, and "M11: Export dialog interactions pass".

**Fixed in this audit:**
- **Video audio overshot −1 dBTP.** Normalised to a −1 dBTP ceiling, Crease's video decoded at −0.90 dBTP (AAC) and −0.91 (Opus, from −1.5). The video's ceiling is now −1.5 dBTP for AAC and −2 for Opus (`videoLoudnessCeiling`); the WAV keeps −1. This deviates from §12's "a true-peak ceiling of −1 dBTP" for the video only (build log).
- **Interactions pass:** Enter in a text field started an export; focus fell to the page in five places; a bigger preview on wide screens; WebKit skipped the Preset group in the Tab order while Custom was chosen (build log "M11: Export dialog interactions pass").

**New tests:** e2e `export-keys.spec` (12) and `m11-acceptance.spec` (4); `video-youtube.spec` gate raised to 40 dB PSNR, plus a long run (`M11_LONG=1`).

**Runs on this tree** (macOS, 6 cores, shared; `--maxWorkers=2`, Playwright `--workers=1`, ports 5680/4680):
- e2e `export-keys`, `m11-acceptance`, `video-youtube`, `youtube-dialog` on chromium-dev, chromium-prod, firefox-dev: 71 passed, 10 skipped (dev-only or long checks).
- WebKit (`E2E_WEBKIT=1`, webkit-dev): `export-keys` and `youtube-dialog`: 19 passed (after fixing one test race in `youtube-dialog`).
- Long run (`M11_LONG=1`), chromium-dev: passed (below).
- `pnpm lint`, `pnpm typecheck` clean; `pnpm test`: 2,970 passed; the only failures are the known `live-take-random` timeouts (5 s, load average 8–15).

Status key: **C+P** covered and passing; **Part** partly covered; **Logged** measured once, not gated; **Owner** needs the owner's eyes.

## Gaps and findings (read first)

1. **Deviation: the video's true-peak ceiling** is −1.5 dBTP (AAC) / −2 dBTP (Opus), not §12's −1, so the *decoded* file meets ≤ −1 dBTP. WAV unchanged. Integrator: note in PLAN if accepted.
2. **Firefox has no AAC encoder:** its videos carry Opus. The line says "AAC wherever offered", so it passes; QuickTime/iPhone playback of Opus-in-MP4 is the owner's call.
3. **4K60 whole piece is logged, not gated,** and only on Chromium (3 min wall). Firefox and WebKit are gated on 2 s 4K60 spans only (Firefox 45.2 dB; WebKit not run here, since it needs play).
4. **Delivered bitrate is far below the target** (2 s 4K60: 8.0 Mb/s of 68 Mb/s on Chromium, 3.7 on Firefox; whole piece 15.4 Mb/s). Quality still ≥ 40 dB; YouTube re-encodes anyway (build log Y3).
5. **SVG approximates** the solid-colour Look: 37 dB (Chromium) and 31 dB (Firefox) against the PNG; glow is a filter there.
6. **WebKit keyboard (native, not changed):** Tab skips buttons unless macOS keyboard navigation is on (Option-Tab works), and the arrow keys stop at the ends of a radio group.
7. Known from M9: macOS WebKit transparent posters' translucent colours.
